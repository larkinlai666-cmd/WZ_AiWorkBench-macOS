【核心 · Cmd 系主键（推荐）】
  Cmd+T            新 Init 面板页签（冷启动自动进入面板）
  Cmd+F1           本速查面板（开关）
  Cmd+F3           Init 面板
  Cmd+F4           关闭当前窗格（有确认）
  Cmd+F6           三栏 AI 桌（agent + shell + 监视）
  Cmd+F7           Explorer 侧栏（当前任务根）
  Cmd+R            重载配置（WezTerm 默认）

【F 键直按 · 与 Windows 同键位】
  F1 速查  F3 Init  F4 关窗格  F5 重载  F6 三栏  F7 Explorer
  （媒体键模式下按住 Fn：Fn+F1/F3/F4/F5/F6/F7；系统设置开启
  "标准功能键"后可直接裸按。F2 留空给 agent 自身）

【键位原则】
  工作台键全部窗口内消化，不抢 agent 字母键；
  无 Leader 层；Cmd+W/H/D/E 保持 macOS 系统默认行为。
  为什么不用 Cmd+Shift+字母：WezTerm 会把它规范成裸
  Cmd+字母，抢走 Cmd+W 关标签、Cmd+H 隐藏应用等系统键。

【Init 面板（静态屏 · 行输入）】
  wz> 数字            选任务 → agent> 再选模型
  wz> <任务><agent>   两位数一次直启（≤9 任务时）
  wz> n<数字>         强制新会话 → 选模型
  wz> c               新建任务向导（名 → 位置 → agent → 确认）
  wz> s               纯 shell 页签
  wz> a               全量视图切换
  wz> d               grok Dashboard
  wz> r               刷新
  wz> q               退出面板（关标签）

【Explorer 面板（静态屏 · 行输入）】
  explorer> 数字      进入目录 / 打开文件 / 跳收藏
  explorer> 0/..      上级目录
  explorer> s         回到 DESK 根
  explorer> g         AI@当前视图    gd = AI@DESK
  explorer> b         绑定当前视图为任务根
  explorer> w         纯 shell 页签
  explorer> p         复制路径
  explorer> f         收藏/取消收藏
  explorer> r/a       刷新 / 自动刷新开关
  explorer> q         退出面板（关标签）
